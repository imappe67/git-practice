# 骸骨王 vs 魔法兵士 — 凍結氷原・30秒シームレスカット

`SCENE.md` の絵コンテ（スタイル／シーン／被験者A・B／0:00–0:30 のアクション）を、
HTML5 Canvas 上で **手続き的に描画する 30 秒のアニメーション** として実装したものです。
画像・動画素材は一切使わず、すべてコードで描いています（ビルド不要・依存なし）。

## 再生方法

```bash
# どちらでも可
open skeleton-king-battle/index.html          # ブラウザで直接開く
npx http-server skeleton-king-battle -p 8080   # ローカルサーバ経由
```

| 操作 | 内容 |
| --- | --- |
| `Space` | 再生 / 一時停止 |
| `←` / `→` | 1コマ（1/24秒）送り、`Shift` 併用で 1 秒 |
| シークバー下のラベル | 各セクション（0:00, 0:04, 0:08 …）へジャンプ |
| `?t=14.4` | 任意の時刻で停止した状態から表示（例: `index.html?t=14.4`） |

全フレームが時刻 `t` の純関数として決まる（パーティクルも含めて決定論的）ため、
どこへシークしても同じ絵になります。`window.renderAt(t)` でヘッドレス書き出しも可能です。

## 絵コンテとの対応

| 指定 | 実装 |
| --- | --- |
| セルシェーディング／シャープなアウトライン | 全パーツを「黒アウトライン → ベース色 → 2値の影 → ハイライト」の順で描画（`boneSeg`, `goldPlate`, `polyFill`） |
| 兵士のみフレームスミア（雷を纏う光の筋） | 移動中は軌跡を白芯＋白菫グロー＋ジグザグ電光の筋として描画、攻撃の瞬間（イベント前後 ~0.13 秒）だけシャープな人型に戻る（`drawStreak` / `drawSoldierSolid`） |
| 骸骨王は筋にならず量塊のまま | 50 m の骨格リグ（IK の四肢・ギャロップ歩容・鹿角の獣頭蓋・金鎧・鎖・煙になるマント・錆と熾火の剣） |
| 踏み込みごとに六角形の氷板が砕ける | 歩容の接地を事前計算 → 放射状の亀裂デカール＋氷片バースト |
| 白い閃光／ネオンの閃光／シルエットの閃光 | `white`＝白飛び＋集中線、`neon`＝色反転＋残火オレンジ/白菫のスクリーン合成、`sil`＝白地に黒シルエット |
| 超インパクトフレーム（0:14.4 / 0:26.7） | 白 → 黒シルエット → オレンジと白菫を入れ替えた反転ネオン → 白、の 0.34 秒シーケンス |
| 超速スロー（0:11.6–0:14.4） | 物理時間をワープ（`timeScale` = 0.07）。粉雪・火の粉・残光はワープ時間で動き、髪とマントがゆっくり流れる |
| 兵士の微笑が消える／戻る | フルフレームのクローズアップ・カットイン（0:12.25 で笑みが消え、0:16.4 で戻る） |
| 胸元の金鎧が引き千切れて飛ぶ | 0:14.72 で剥離 → 放物線で 0:16.0 に氷原へ突き立つ → 0:17.15 に剣で兵士へ吹き飛ばされ、0:17.85 に兵士が踏み台にする |
| 自分で作った氷の帯 | 0:06.2 の縦の一撃で斜めにせり上がる 23 枚の氷板。骸骨王が近づくと倒れ、0:23.3 の電光で残りが崩壊 |
| 融解痕がガラス状に再凍結 | 筋が氷面すれすれを通過した軌跡を、紫電（0.35 秒）→ 青白いガラス光沢（9 秒で減衰）として描画 |
| 剣先を引きずって火花の線 | 剣先が接地するフレームを事前計算 → 熾火の残る黒い溝＋火花 |
| 磨かれた氷面の照り返し | 胸郭の熾火と兵士の雷を、氷面上に縦の筋状反射として描画 |
| 0:28–0:30 正面ショット | 霧を割って走り出る兵士の正面図、回転しながら落ちる槍を頭上で掴み肩に担ぐ、口角が上がって薄菫色のレンズフレア |

## ファイル構成

```
skeleton-king-battle/
├── index.html        プレーヤー UI
├── SCENE.md          元の絵コンテ（指示文そのまま）
└── js/
    ├── core.js       数学・キーフレームトラック・決定論的乱数・時間ワープ・パレット
    ├── king.js       骸骨王：振付トラック、リグ（IK/歩容/剣の接地）、セル描画
    ├── timeline.js   兵士の経路（骸骨王の骨に追従するアンカー付き）、攻撃イベント、カメラ、カットイン
    ├── world.js      カメラ投影、六角亀裂の氷原、氷の帯、氷塊、飛翔物、デカール、地吹雪
    ├── soldier.js    兵士：経路補間、筋⇔シャープ形態の切替、ポーズ、側面セル描画
    ├── fx.js         火花・氷片・火の粉・雪煙のバースト、稲妻の閃条、衝撃波、インパクトフレーム
    ├── hero.js       顔のクローズアップ、骸骨王の眼窩カットイン、0:28 以降の正面ショット
    └── render.js     奥行きソート合成、グレーディング、プレーヤー
```

振付の調整は `timeline.js`（兵士・イベント・カメラ）と `king.js` 冒頭の `KING.tr`（骸骨王）の
キーフレームを編集するだけで反映されます。

## 補足

元の指示文にある `@Image 1`（骸骨王）と `@Image 2`（魔法兵士）の参照画像はリポジトリに含まれていないため、
キャラクターデザインは指示文中の文字による描写（鹿角の獣頭蓋・赤橙の眼光・彫金入りの金鎧・暗赤色のマント／
漆黒のセンター分けロングヘア・白いキルティングコート・油膜光沢の金属装備・黒布巻きの槍 など）から起こしています。
