# ほしまいご — Hoshi-maigo (The Lost Little Star)

A 60-second 2D animated short: **`out/hoshimaigo.mp4`** (1920×1080, 30 fps, Japanese dialogue with subtitles).

> 百年に一度、星が迷子になる夜がある。
> On a summer night, Hina finds a crying star-creature, Kira, in the rice field.
> The whole town's "thank-you" light carries it home — with a promise to meet every year.

Everything is generated by code. No drawn assets, recorded audio, samples or stock music were used.

| Layer | How |
|---|---|
| Art & animation | Vector character rigs + painted-look backgrounds on HTML5 canvas (`render/`), rendered frame-by-frame in headless Chromium by 4 parallel workers |
| Voices | VOICEVOX engine running locally — 5 characters, emotion styles per line (`tools/gen_voice.py`; credit: VOICEVOX: 青山龍星, 四国めたん, ずんだもん, ちび式じい, 白上虎太郎) |
| Lip-sync | Mora/phoneme timings from VOICEVOX's `audio_query` drive the mouth shapes (a/i/u/e/o/n/closed) frame by frame |
| Score | Synthesized orchestra (additive, modal, Karplus-Strong and FM synthesis, convolution reverb) in D♭ major (`tools/gen_music.py`) |
| Sound design | Procedural crickets, frogs, wind, footsteps, shōji doors, bells and the meteor burst, all tuned to the score's key (`tools/gen_sfx.py`) |
| Mix | Dialogue placement, side-chain ducking, limiter, −16 LUFS (`tools/mix.py`) |

The single source of truth for timing is `story/timeline.json`; `BRIEF.md` is the art bible.

## Rebuild

```bash
./build.sh              # music, sfx, mix, render video, mux  (VOICES=1 also regenerates dialogue; needs VOICEVOX on :50021)
node render/render.mjs still 15 42.5 --out preview   # PNG stills of any moment
```
